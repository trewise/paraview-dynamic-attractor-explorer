# Dynamic Attractor Observatory Portfolio

This folder contains the portfolio-facing version of the project.

## Project Summary

Dynamic Attractor Observatory is a scientific visualization pipeline for nonlinear dynamical systems. It generates chaotic attractor datasets, exports ParaView-compatible files, creates density volumes, validates outputs, runs parameter sweeps, and prepares rendering scripts for scientific visualization.
