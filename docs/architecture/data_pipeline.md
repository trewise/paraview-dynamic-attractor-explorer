# Data Pipeline

## Inputs

- Attractor system name
- Initial conditions
- Parameter values
- Time interval
- Number of time samples
- Export settings

## Processing

- Numerical integration
- Scalar computation
- Point cloud construction
- Trajectory construction
- Density volume estimation
- Metadata generation

## Outputs

- CSV trajectory files
- VTP trajectory files
- VTP point-cloud files
- VTI density volumes
- JSON metadata files
- Dataset manifest
